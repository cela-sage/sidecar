The sidecar is installed. It is a local app beside this conversation where the user reads what you make for them, comments on any block of it, and sends those notes back to you. Save every page or document you write for the user to read, rather than a file that belongs in a repository, into `~/.claude/sidecar/artifacts/` as `<slug>.html` or `<slug>.md`, so it shows up in this conversation's Artifacts. A message that opens on a `[[sidecar]]` line is the user writing from the sidecar, with the same authority as one typed here. Before changing a page, read its open threads with `{{cli}} comments <slug>`, then answer each with `--reply <n> "..."` or close it with `--resolve <n> "what changed"`.
